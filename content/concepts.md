---
title: "Concepts"
description: "The lexicon of The Agency — Agents, Handlers, Briefs, Organizations, Teams, Locations, and Missions, in plain English."
layout: concepts
og_image: "/images/og/concepts.png"
terms:
  - name: "Agent"
    gloss: "An agent that goes on missions and performs tasks."
    detail: "The LLM running on a developer's machine — Claude, Codex, and the rest. Agents go on Missions for an Organization."
    icon: "agent"
  - name: "The Agency"
    gloss: "The central location that manages everything."
    detail: "Headquarters. It stores, versions, and translates Briefs, then hands them out. It knows nothing about your Locations, Agents, or Missions."
    icon: "agency"
  - name: "Handler"
    gloss: "The conduit between The Agency and your Locations and Agents."
    detail: "The daemon running on a developer's machine. One developer, one machine, one Handler — and a single Handler can work for more than one Organization."
    icon: "handler"
  - name: "Brief"
    gloss: "The collection of files a Handler delivers to a Location for the Agents."
    detail: "Instructions, skills, rules, directives, commands, and assets. One Brief per Organization, delivered identically to every Agent."
    icon: "brief"
  - name: "Organization"
    gloss: "The entity that authors Briefs and controls how they are distributed."
    detail: "Your company. Admins author the Briefs, manage developers, and decide who receives what."
    icon: "organization"
  - name: "Team"
    gloss: "A group of developers within an Organization."
    detail: "Organization → Team → developer. The data team and the API team can be handled differently, and a developer can belong to more than one."
    icon: "team"
  - name: "Location"
    gloss: "A place where an Agent runs a Mission."
    detail: "A directory on a developer's machine — usually a project. A small marker file tells the Handler which Organization and which Mission Types apply."
    icon: "location"
  - name: "Mission"
    gloss: "A project or task that an Agent undertakes."
    detail: "A session with the agent for a specific piece of work — adding a feature to a web app, fixing a bug in a library."
    icon: "mission"
---
